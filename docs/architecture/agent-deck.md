# Agent Deck 本地接入

Dao 进程拥有会话、调度器和任务，面板通过本地 HTTP 协议观察并提交指令。面板断连或重启不会关闭 Agent；Dao 退出时关闭监听并删除发现记录。

## 启动与发现

- 默认开启桥接；DAO_DECK=0 可关闭。
- DAO_DECK_MANAGED=1 使用面板作为交互输入来源，等待用户消息、问题答复和审批；不启动 Ink 输入。不能同时关闭桥接。
- 在 AGENT_DECK_HOME/agents 下写发现记录，默认目录为 ~/.agent-deck。目录权限 0700、记录权限 0600。记录包含本地随机端口、会话 ID 和随机 Bearer 令牌，不应上传或记录到日志。
- 仅监听 127.0.0.1；所有请求需令牌，带 Origin 的请求直接拒绝。浏览器面板应经自己的本地后端访问。

## 协议

| 请求 | 行为 |
|---|---|
| GET /snapshot | 调度状态、实时文本、问题/审批、任务、Todo、用量、费用估算、最近历史与输入回执 |
| GET /messages?before=N | 向前分页读取非系统消息，返回 nextBefore / hasMore / revision |
| POST /command，type=message | 提交用户文本，经同一调度器与 UserPromptSubmit hook 处理 |
| type=pause | 中断当前回合，取消排队输入，待答审批按拒绝处理 |
| type=answer | 以 promptId 答问题或决定允许本次/拒绝，不创建持久放行规则 |
| type=permission | 仅可在交互会话 idle/paused 且没有待答问题时切换已接入的权限模式 |

每条指令需唯一 id 与当前 sessionId；相同 ID/内容重试幂等，相同 ID/不同内容被拒。去重缓存保留最近 200 条。会话切换清除旧回执、事件和问题；旧会话指令返回 409。message 回执区分 queued、consumed、rejected 与 canceled。

一次性任务不能追加聊天输入或切换权限，托管下可答复正在等待的问题与审批。普通终端会话的问答与审批仍在终端完成，面板展示待关注状态。托管模式把结构化选项完整显示给面板，数字/多选回答按终端相同规则解析。权限控制类斜杠命令不能作为聊天消息绕过权限入口；其他斜杠文本按普通用户消息处理。

历史每页最多 100 条、约 1.2MB；单条正文与工具参数有独立上限和截断标记。图片以附件提示展示，不通过此接口分发图片数据，系统消息与加密推理项也不下发。费用沿用 Dao 的模型成本估算，不代表供应商账单。

## 验收

就近测试覆盖令牌、跨域拒绝、幂等回执、hook 拒绝、问答/审批、中断、权限切换、会话隔离、分页与事件转发。deck_cli.integration.test.ts 运行真实 Dao 入口，使用隔离 HOME/工作目录与本地假模型，验证带 --model 启动不会变成一次性任务，以及消息 → 结构化问答 → 审批写入 → Bash 验证 → 面板重连 → 暂停的完整流程，不消耗模型额度。
